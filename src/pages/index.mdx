<FeaturesGrid
  heading="Built for how developers actually work"
  sub="Everything you need for structured, AI-assisted planning, without locking you into a single agent, source of truth, or workflow."
>
  <FeatureCard icon="📄" title="Spec-driven workflow">
    Write a markdown spec. Spektacular drives plan and implement from it,
    keeping intent reviewable at every stage.
  </FeatureCard>

  <FeatureCard icon="💬" title="Flipped Interaction interview">
    Spektacular interviews you before drafting a spec, asking adaptive
    questions instead of a fixed script, so you get a complete spec even
    when you haven't fully thought the feature through yet.
  </FeatureCard>

  <FeatureCard icon="🧩" title="Pluggable architecture">
    Specs, plans, and knowledge are stored behind a Store interface. The
    coding agent is behind an Agent interface. Swap either out.
  </FeatureCard>

  <FeatureCard icon="🧠" title="Multi-source knowledge">
    Combine project, team, and global knowledge sources. Spektacular searches
    them in order and tags each result by scope.
  </FeatureCard>

  <FeatureCard icon="🤖" title="Multi-agent support">
    Ships with Claude Code, Bob, and Codex agents. Pick the one your team
    already uses, or register your own.
  </FeatureCard>

  <FeatureCard icon="⏯️" title="Resumable workflows">
    Spec, plan, and implement each run as stepwise state machines. Stop,
    inspect, edit, and resume: no work is lost.
  </FeatureCard>

  <FeatureCard icon="🔓" title="Open source">
    Apache 2.0 licensed. Build on it, extend it, run it anywhere. Contributions
    welcome.
  </FeatureCard>
</FeaturesGrid>
