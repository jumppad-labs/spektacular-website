# Multi-repo projects documentation

A new "Multi-Repo Projects" reference page (`/projects/`) explains Spektacular's multi-repo "projects" capability: what it is and why it's useful, how a repository is registered, how project-level and repository-level configuration relate to each other as one coherent topic, how planning and implementation work is attributed across repositories, how a repository becomes available locally, and how paths can be excluded from search. The page uses the spektacular project's own live registration (this repo plus its own colocated repo) as its worked example, is built from the site's existing reference-page components, and is reachable from the site's "Resources" navigation menu.

The getting-started tutorial gained one pointer sentence, at the end of its project-initialization step, linking to the new page for readers who might otherwise assume a project is limited to a single repository. No other part of the tutorial changed.
