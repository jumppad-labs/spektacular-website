Install Spektacular

Get Spektacular running on your machine in under a minute.

Choose your install method

Pick the method that fits your workflow.

Homebrew

Install via the official Homebrew tap:

$ brew install jumppad-labs/homebrew-repo/spektacular

Debian / Ubuntu

Add the apt repository and install:

echo "deb [trusted=yes] https://apt.fury.io/jumppad/ /" \
  | sudo tee /etc/apt/sources.list.d/spektacular.list
sudo apt update
sudo apt install spektacular

GitHub Releases

Download the latest release archive from GitHub Releases, extract the binary, and move it to a directory on your $PATH.

macOS (Apple Silicon)

tar -xzf spektacular_Darwin_arm64.tar.gz
sudo mv spektacular /usr/local/bin/

macOS (Intel)

tar -xzf spektacular_Darwin_x86_64.tar.gz
sudo mv spektacular /usr/local/bin/

Linux (x86_64)

tar -xzf spektacular_Linux_x86_64.tar.gz
sudo mv spektacular /usr/local/bin/

Linux (ARM64)

tar -xzf spektacular_Linux_arm64.tar.gz
sudo mv spektacular /usr/local/bin/
